# 充桩条

开会话 → 计量脉冲累加 → 结算关账 → 超时/异常命运。

## 急停中断残额口径（全局唯一，方案 B：残额钉枪缺口口径）

中断保留**可结算残额**，全项目只贯彻这一种，不得混用；
态字允许先落，但枪线/残额/脉冲证据不齐时，**必须写可核缺口并冻结急停宣称**：

- 中断回执：冻结残额（电量 × 锁定单价 = 金额），写 `aborted_at / abort_reason`，落“异常中断”事件；
  回执由事实表重放，带 `急停宣称`（无未清缺口才为真）与 `缺口` 清单；
- 占用：中断即释放桩位与枪线（只把“占用”翻回空闲/可用，不动人工置的故障/维护）；
- 脉冲：中断后拒绝再记脉冲，残额不再变动；脉冲电量和与冻结电量在回执里对账；
- 可核缺口：`abort_gaps` 持久化四类缺口——枪线未释放 / 残额静默清零 / 脉冲电量漂移 / 中断态半截；
  `POST /api/缺口对账` 重评证据，补齐即核销、不成立即登记；
- 冻结：缺口未清前，中断页与总览不得亮“已中断齐”，关账入口禁止收口（409），防止存疑残额假绿入账；
- 收口：证据齐的已中断会话允许在结算入口走**一次**收口（`已中断 → 已关账`），
  收口金额恒等于冻结残额，另落“中断结算收口”事件与 `settled_at`；
- 展示：详情、中断页、回执、充日“未结”、总览“已中断”桶同源（同一份缺口与残额事实），不在展示层另算；
- 对账：`GET /api/中断对账` 暴露“已中断仍占用 / 残额静默清零 / 脉冲与电量漂移 / 中断态半截 / 未清缺口”；
- 原子与并发：写入口统一 `BEGIN IMMEDIATE`，中断、脉冲、关账互斥；
  中断事务任一步失败整笔回滚，不留“态字已改枪线仍钉”，并发下残额不双挂；
- 旁路禁令：不存在总览快照/回执覆盖层，禁止只改急停按钮或旁路改中断态字；
  旧 `surface_*` 毒快照在 `init_db` 时清除。

超时强制关不在本口径内（另立需求）。

- 前端 http://127.0.0.1:6500
- API http://127.0.0.1:11500

```powershell
# 本地 API
cd backend
py -3.11 -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
$env:PYTHONPATH = (Get-Location).Path
.\.venv\Scripts\uvicorn.exe app.main:app --host 127.0.0.1 --port 11500

# 本地前端（另开）
cd frontend
npm install
npm run dev
```

或 `docker compose up -d --build`。
